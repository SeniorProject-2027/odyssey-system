## 📖 System & Developer Manual

### Prerequisites

Download and install [Node.js](https://nodejs.org/en/download), [pnpm](https://pnpm.io/), [uv](https://docs.astral.sh/uv/) and [Docker](https://docs.docker.com/get-started/).

### Installation

```sh
pnpm install:all
cp odyssey-config.example.hjson odyssey-config.hjson
pnpm db:start
pnpm dev
```

### How to Run It

- `pnpm dev` runs the server, client and desktop app together.
- `pnpm test` runs the tests.
- `pnpm lint` fixes formatting.
